# load-weekly-cases

Loads the Weekly Cases from `scripts/weekly/cases/` into `public.weekly_cases` and `public.weekly_case_scoring`.

- `data/index.ts` is generated by `node scripts/weekly/export.mjs --write`. Do not edit it by hand.
- `GET` previews what would change per week and writes nothing. `POST` writes it.
- Per week the plan is `insert`, `update`, `current` (nothing to do) or `locked`.
  A week that has closed is never rewritten. A week that has opened never has its part ids changed (answers are stored by part id).
  A stored `status` is never touched, so setting a case to `archived` in the database vetoes it.
- No sign-in: it can only write the bundled content, only rows that differ, so a second call writes nothing.
- The migration `0044_weekly_cases.sql` schedules `weekly-case-load` (every six hours) to POST it, so merging a case PR is all that is needed.
  To load by hand right now: POST to `https://<project>.supabase.co/functions/v1/load-weekly-cases`.
